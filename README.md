### finalproject_Nechaeva_Anna_M25-555
### Учебная платформа для симуляции торговли валютами

### Инструкция по запуску 

1. Установка зависимостей: make install
2. Запуск программы: make project
3. Сборка проекта: make build
4. Публикация: make publish
5. Установка всех необходимых пакетов: make package-install
6. Проверка кода в соответствии с ruff: make line

### Инструкция по работе с приложением:

1.  **register** - регистрация  (новому пользователю 10 000 USD)
2.  **login** - вход в аккаунт
3.  **portfolio** - просмотр финансового портфеля
4.  **buy** - покупка валюты 
5.  **sell** - продажа валюты
6.  **get-rate** - просмотр списка курсов валют
7.  **show-rates** - просмотр списка курсов валют 
8.  **update** - обновление списка валют 
9.  **parser** - состояние парсера
10. **autoupdate** - запуск автоматического обновления парсера
11. **stop** - остановка автоматического обновления парсера
12. **exit** - выход из приложения

### Идея проекта
Это комплексная платформа, которая позволяет пользователям регистрироваться, управлять своим виртуальным портфелем фиатных и криптовалют, совершать сделки по покупке/продаже, а также отслеживать актуальные курсы в реальном времени. Система состоит из двух основных сервисов:
Сервис Парсинга (Parser Service): Отдельное приложение, которое по запросу или расписанию обращается к публичным API, получает актуальные курсы, сравнивает их с предыдущими значениями и сохраняет историю в базу данных.
Основной Сервис (Core Service): Главное приложение, которое предоставляет пользовательский интерфейс (CLI), управляет пользователями, их кошельками, историей транзакций и взаимодействует с сервисом парсинга для получения актуальных курсов.
